With one fixed evaluation order, trees built from the $S$ combinator alone can compute every partial computable function on binary strings. This is the weaker deterministic form of universality discussed in Wolfram's prize announcement. A finite tree encodes the program and input. Each round marks the innermost places where the $S$ rule applies, then reduces them from left to right.

The tree enumerates candidate histories of one universal machine. Two scans driven by $S$ align corresponding tape cells in successive rows, however wide the rows are. A fixed finite tree automaton checks the machine's transition rule on these cells at round boundaries. A fixed decoder reads the answer from the last row. Every report is correct, and a report occurs exactly when the program halts. For pairs of a program index and a numerical input, reaching one fixed regular tree language is r.e.-complete, although normalization of ground $S$-terms is decidable. The proofs were formalized in Lean and checked with Nanoda.
